## 해석

평균 API 응답시간 897.06ms 중 평균 락 획득 대기시간이 891.39ms로 대부분을 차지했습니다. 동일 상품 요청이 하나의 락 앞에서 순차 처리되면서 대기시간이 누적되는 형태입니다.

락 점유시간은 평균 4.15ms입니다. 짧은 시간처럼 보여도 동일 상품 요청은 이 구간을 동시에 실행할 수 없으므로 요청이 집중되면 앞선 요청의 점유시간이 뒤 요청의 대기시간으로 누적됩니다.

현재 상품 조회와 재고 조회·차감·응답 생성이 모두 락 내부에서 실행됩니다. 다음 단계에서는 상품 조회처럼 재고 정합성 보호에 직접 필요하지 않은 작업을 락 밖으로 이동하고, 동일 조건으로 다시 측정하여 락 점유시간 감소가 API 응답시간과 TPS 개선으로 이어지는지 검증합니다.

이번 baseline만으로 큰 개선 폭을 단정할 수는 없습니다. 리팩토링 후 수치 변화가 작다면 그것도 상품 조회가 주요 비용이 아니었다는 측정 결과로 기록합니다.
